# Every page links to the accessibility statement

Every page must link to the Erklärung zur Barrierefreiheit of the platform at
`/barrierefreiheit`. The statement must name the spec explorer.

Reason: § 10 L-BGG requires a statement that the user can find from every page. One
statement for both apps is sufficient.
